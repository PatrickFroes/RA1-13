# Analisador léxico e Gerador de Assembly para ARMv7

Trabalho para a disciplina de Construção de Interpretadores, do sétimo período do curso de Ciência da Computação na PUCPR, com o professor Frank de Alcantara.

Realizado pelos aluno Gabriel Antony Olsson Schlagenhaufer (`misfasol`) e Patrick Froes (`PatrickFroes`).

## Execução

Para executar o programa utilize o comando `python ParseEXP.py NOME_DO_ARQUIVO`, em que `NOME_DO_ARQUIVO` é um arquivo que possui expressões aritméticas em notação polonesa reversa separadas me linhas.

## Testes Unitários

Para realizar testes em cada função do programa de maneira separada acesse TestesUni.py, neste arquivo existem diferentes funções com propósito de testes unitários, preencha as listas de cada função com as expressões desejadas para teste e rode o programa.
